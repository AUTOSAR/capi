# Release Notes for the First Release of AUTOSAR CAPI

**Title**: CAPI 1.0

**Release tag**: v1.0.0

**Release tag message**: First AUTOSAR CAPI release


## First AUTOSAR CAPI Release

This first release is contributed by  ``iSOFT Infrastructure Software Co., Ltd.``. 
It mostly follows the widely-used AUTOSAR Adaptive Platform release R20-11 and has forward-looking compatibility with some R23-11 interfaces. 
It implements all 15 core functional clusters including Communication, Execution Management, Logging, and Diagnostics.
A demo with a prepared setup so that it can be run easily is also included. (See: [README](https://github.com/AUTOSAR/capi/blob/v1.0.0/README.rst))
