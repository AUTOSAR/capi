# Security Policy

## Supported Versions

- [Latest published release](https://github.com/autosar/CAPI/releases)
- HEAD of the main branch

We are nonetheless very thankful for reports concerning older versions as well.

## Reporting a Vulnerability

Please contact us if you have information about a security issue or vulnerability in CAPI.
Please do not use public issues to report vulnerabilities.
Instead, send reports via email to <capisecurity@autosar.org>.

Please provide as much context and information as possible. For example:

- Description with sufficient detail to reproduce the findings
- Possible effects
- What is needed to exploit the vulnerability
- An attack scenario
- Information about known exploit
