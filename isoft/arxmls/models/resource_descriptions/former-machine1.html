资源概览

该资源具有如下特征：

一、机器基本信息

该机器默认包含如下基本信息：

  • 双核： core0 与 core1
  • 1个资源组： ResourceGroup

二、机器服务情况

该部分资源包含的服务情况如下：

  • 已实例化了所有平台模块
  • 服务设定

三、预置的软件集&软件包

该部分资源含预置的 软件集、软件包 等；包含：core、framework、os 三个软件集，

各软件集：

  1. core 与 framework 软件集
  1. os 软件集

四、预置的集成基础

该部分资源提供 预置的功能组、预定义的机器信息 三部分，为 必要资源。

4.1、预置的功能组

MachineFG:

即 机器功能组，此功能组为特殊功能组，用于描述 Machine 的运行状态。

ProcessStateMachine：

即 进程状态机，此功能组为特殊功能组，用于描述进程所处的生命周期。

4.2、预制的状态机

新增状态机（StateMachine）功能，默认提供名为 MachineSM 的状态机。

4.3、预定义的机器信息

该部分包括如下内容：

  • machine_design
  • network_manifest
  • udp-nm-cluster
  • time_domain

五、添加后的资源路径
